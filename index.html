📖 Documentación — Animation Editor

🗂️ Carga de archivos

El editor necesita hasta tres archivos. Puedes arrastrarlos (drag & drop) al viewport o usar los botones de la barra superior:

  • Atlas PNG — la imagen sprite-sheet (puede ser .png, .jpg, .webp). Si el nombre contiene @2x, -uhd o similar, se detecta automáticamente como UHD.
  • Atlas Data — JSON o Plist con la información de recorte de cada sprite del sheet (frames).
  • AnimDesc — JSON o Plist con el descriptor de animaciones (animationContainer, usedTextures).

Cuando los tres están cargados aparece el botón "Abrir Editor". También puedes pulsar "Crear desde cero" con solo PNG + Atlas.

🎞️ Panel izquierdo — Animaciones & Partes

  • La lista superior muestra las animaciones. Pulsa en una para activarla.
  • El botón "+" abre el modal para crear una nueva animación.
  • La lista inferior muestra las partes/sprites del frame actual, ordenadas por capa y zValue.
  • Usa los botones 📄 (Copiar) y 📋 (Pegar) para duplicar partes fácilmente.

🖼️ Viewport — Canvas principal

  • Click izquierdo sobre un sprite → lo selecciona. Si varios se solapan, clicks sucesivos ciclan por capas.
  • Arrastrar un sprite → mueve todas las partes seleccionadas.
  • Click en el fondo → deselecciona los sprites activos.
  • Arrastrar en vacío → paneo del canvas.
  • Shift+arrastrar en vacío → dibuja una caja de selección multi-partes.
  • Shift+click o Ctrl+click → selecciona o deselecciona múltiples partes en la lista.
  • Rueda del ratón → zoom in/out.
  • 📱 Móvil: un dedo arrastra o panea, dos dedos hacen pinch-to-zoom. Mantén pulsado en espacio vacío para activar la caja de selección táctil multi-partes (con vibración háptica).

⏱️ Timeline

  • Haz click o arrastra (scrubbing) sobre los números del timeline (regla) o en las celdas inferiores para cambiar de frame.
  • +Fr / −Fr duplica o elimina el frame actual.
  • Usa los botones 📄 (Copiar Frame) y 📋 (Pegar Frame) para clonar cuadros completos.

⚙️ Panel derecho — Propiedades

  • Muestra y edita la posición (X, Y), escala (SX, SY), rotación y zValue de la parte seleccionada.
  • 💡 Tip de velocidad: Puedes hacer clic y arrastrar (izquierda/derecha) sobre los cuadros de texto numéricos para cambiar su valor fluidamente. Mantén presionado `Shift` para que el valor cambie más rápido.

↩️ Deshacer / Rehacer y Atajos

  • Ctrl+Z / Ctrl+Y → deshacer / rehacer.
  • Ctrl+C / Ctrl+V → copiar y pegar sprites (o frames si no hay partes seleccionadas).
  • Delete / Backspace → Eliminar partes seleccionadas.
  • Shift + Flechas → Mover parte 1px (o 10px con Ctrl).
  • T → Activar/Desactivar interpolación suave.
